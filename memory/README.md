## 한눈에 보기

- **기술**: Electron 44 + React 19 + TypeScript + Vite, 영상 처리는 FFmpeg 6.1(`ffmpeg-static`), 음성 인식은 whisper.cpp(내 PC에서 실행)
- **규모**: 소스 약 5,800줄 (`src/` 렌더러, `electron/` 메인 프로세스)
- **실행**: `npm run dev` / 설치 파일: `npm run dist` → `release\영상편집기-설치-0.1.0.exe`

## 주요 기능

컷 편집(자르기·분할·순서 변경) · 배속 · 배경음악(볼륨·페이드·영상 길이 맞춤) · 바로 녹음 ·
자동 자막(whisper) + 자막 편집 · 전환 효과 8종 · 텍스트 레이어(애니메이션) ·
MP4 내보내기(+SRT) · 프로젝트 저장/열기 · 자동 저장/복구 · 최근 프로젝트 · Windows 설치 파일
