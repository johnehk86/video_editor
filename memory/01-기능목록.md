# 기능 목록과 사용법

## 화면 구성

```
┌ 상단: 새로 만들기 · 📂 열기 ▾(최근) · 💾 저장 · 다른 이름으로 · 프로젝트 이름(● 저장 안 됨) · 내보내기 ┐
│ 왼쪽 탭: 🎞 미디어 / 💬 자막 │ 가운데: 미리보기(16:9) │ 오른쪽: 속성 패널(선택한 것에 따라 바뀜) │
└ 아래: 타임라인 — 🅣 텍스트 · 💬 자막 · 🎞 메인 · 🎵 배경음악 · 🎙 녹음 ┘
```

## 미디어

- 영상·음악·이미지를 **가져오기** 버튼이나 끌어다 놓기로 추가
- 타임라인에 넣기: 카드를 끌어다 놓기 / 더블클릭 / 카드의 `+`
- 영상은 썸네일·길이·해상도, 소리는 음파(웨이브폼) 표시
- 프로젝트를 열었는데 원본이 없으면 빨간 카드(⚠) → 눌러서 다시 연결, 같은 폴더의 나머지 파일은 자동으로 찾음

## 타임라인 편집

| 트랙 | 특징 |
|---|---|
| 🎞 메인 | 영상·이미지. 빈틈없이 이어 붙음(자석 방식). 순서 바꾸기 가능 |
| 🎵 배경음악 | 음악. 자유 배치 |
| 🎙 녹음 | 내레이션. 자유 배치 |
| 💬 자막 | 자막 블록 |
| 🅣 텍스트 | 텍스트 레이어. 시간이 겹치면 자동으로 줄 나눔 |

- 클립 끝을 끌어 길이 조정(트림), `S`로 재생헤드 위치에서 분할, `Delete`로 삭제
- 이미지는 기본 3초
- `Ctrl+마우스휠` 또는 🔍 슬라이더로 확대/축소

## 클립 속성 (오른쪽 패널)

- **⏩ 속도**: 0.1~10배 (빠른 선택 0.25~8x). 목소리 음 높이는 유지
- **🔊 볼륨**: 0~200%, 음소거. 미리보기는 100%까지만 들리고 내보내기에 200%까지 반영
- **페이드 인/아웃**: 0~10초
- 배경음악 클립 전용: **✂ 영상 길이에 맞추기**, **🔁 반복해서 채우기**

## 전환 효과

- 메인 트랙 클립 사이에 마우스를 올리면 `+` 버튼 → 기본 디졸브 0.5초
- 종류 8가지: 디졸브, 검은 화면, 흰 화면, 왼쪽/오른쪽 밀기, 왼쪽/오른쪽 닦기, 원형 열기
- 길이 0.1~2초. 두 클립이 겹치는 방식이라 전체 길이가 그만큼 줄어듦
- 전환은 각 클립 길이의 절반까지만 적용 (넘으면 패널에 노란 글씨로 실제 길이 표시)
- **모든 클립 사이에 적용** 버튼

## 녹음

- 타임라인 도구 막대 **🎙 녹음** → 마이크 선택, 입력 레벨 표시
- 3초 카운트다운 후 녹음. 옵션: 영상을 재생하면서 녹음 / 녹음 중 영상 소리 끄기
- 정지하면 🎙 녹음 트랙의 시작 위치에 자동으로 들어감 (WAV로 저장)

## 자막

- **🤖 자동 자막**: 모델 빠름(base 148MB) / 보통(small 488MB) / 가장 정확(turbo 574MB), 언어 한국어·영어·일본어·자동
  - 영상 소리 + 녹음 트랙만 듣고 배경음악은 뺌
  - 처음 한 번 인식 프로그램(9MB)과 모델을 내려받음. 모든 처리는 PC 안에서
- 직접 편집: 자막 탭 목록에서 바로 입력, `T` 키 또는 자막 줄 더블클릭으로 추가
- 시간: 타임라인에서 끌기, 또는 속성 패널의 시작/끝 입력과 "재생헤드로" 버튼
- 스타일(모든 자막 공통): 크기, 위치(위/가운데/아래), 색, 외곽선, 배경 상자, 굵게
- SRT 불러오기/저장

## 텍스트 레이어

- **🅣 텍스트** 버튼 또는 텍스트 줄 더블클릭 → 재생헤드 위치에 3초짜리 텍스트
- 미리보기에서 **글자를 끌어 위치 이동** (가운데 근처는 자동으로 붙음)
- 글꼴(맑은 고딕·굴림·바탕·궁서·Impact), 크기, 색, 위치, 외곽선, 배경 상자, 굵게
- 등장/퇴장 애니메이션: 없음 · 페이드 · 팝 · 슬라이드

## 내보내기

- 해상도: 1080p(권장) · 720p · 4K · 세로 1080×1920(쇼츠)
- 프레임 24/30/60, 화질 높음/보통/작은 용량, MP4(H.264 + AAC)
- 자막 입히기 여부, SRT 파일 같이 저장 여부 선택
- 진행률 표시, 취소 가능, 끝나면 폴더 열기

## 프로젝트

- `.vproj` 파일로 저장 (원본 경로 + 편집 내용만, 영상은 넣지 않음)
- 프로젝트 파일 기준 상대 경로도 저장해서 폴더째 옮겨도 다시 찾음
- 저장 안 한 채 닫기/새로 만들기/열기 → 저장 여부 확인
- **자동 저장**: 저장 안 한 변경이 있으면 30초마다. 비정상 종료 뒤 다음 실행 때 복구 창
- **최근 프로젝트**: 📂 열기 옆 ▾, 빈 화면에도 표시 (최대 10개)
- 설치 버전에서는 탐색기에서 `.vproj` 더블클릭으로 열림

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 재생/일시정지 |
| `←` `→` / `Shift+←` `Shift+→` | 1프레임 / 1초 이동 |
| `Home` / `End` | 처음 / 끝 |
| `S` | 분할 |
| `T` | 재생헤드에 자막 추가 |
| `Delete` | 선택한 클립·자막·전환·텍스트 삭제 |
| `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) | 실행취소 / 다시실행 |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | 새로 만들기 / 열기 / 저장 / 다른 이름으로 저장 |
