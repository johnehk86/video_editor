# 개발 기록

2026-10-07, 한 단계씩 만들고 단계마다 실제로 실행해 확인하는 방식으로 진행했습니다.

## 처음 정한 로드맵 (7단계)

### 1단계 — 프로젝트 뼈대, 불러오기, 미리보기
- PC에 Node.js만 있고 FFmpeg·Python·Rust가 없어서 **Electron + React + TypeScript + Vite**로 결정
  (추가 설치 없이 바로 시작 가능, FFmpeg는 나중에 npm 패키지로)
- 화면 배치: 왼쪽 미디어 / 가운데 미리보기 / 오른쪽 속성 / 아래 타임라인

### 2단계 — 타임라인
- **메인 트랙은 자석 방식**(빈틈없이 이어짐), 오디오 트랙은 자유 배치
- 나중을 위해 클립에 `speed` 값을 미리 넣어 둠 (4단계에서 그대로 사용)
- 미리보기를 "선택한 파일"이 아니라 **타임라인 전체 재생**으로 변경
- 재생 시계는 매 프레임 바뀌므로 React 상태 대신 외부 스토어(`playback.ts`)로 두고 필요한 곳만 구독
- 실행취소/다시실행(기록 100개)

### 3단계 — MP4 내보내기
- `ffmpeg-static`(FFmpeg 6.1)으로 FFmpeg 별도 설치 불필요
- 타임라인 → FFmpeg `filter_complex` 로 변환. 구간마다 정확한 길이로 맞춰야 이어 붙여도 소리가 안 밀림
- 비율이 다른 영상은 잘리지 않게 맞추고 검은 여백
- 테스트 영상으로 길이(7.00초)·장면을 프레임 단위로 검증

### 4단계 — 배속
- 슬라이더는 로그 눈금(가운데 1배), 연속 조절은 실행취소 기록 하나로 합침
- 소리는 `atempo`를 여러 단계로 나눠 0.1~10배 지원, 미리보기는 `preservesPitch`

### 5단계 — 배경음악
- 클립별 볼륨(0~200%)·페이드, 영상 길이에 맞추기/반복 채우기
- Web Audio로 음파 계산(300MB 넘는 파일은 생략)
- 내보낸 영상의 구간별 소리 크기(dB)를 재서 페이드·볼륨 검증

### 6단계 — 바로 녹음
- 배경음악과 겹치지 않게 **🎙 녹음 트랙**을 따로 만듦
- 브라우저 녹음(WebM)은 위치 이동이 부정확해서 **FFmpeg로 WAV 변환**해 저장

### 7단계 — 자동 자막 + 자막 편집
- 사용자 선택: **내 PC에서 인식(whisper.cpp)** — 무료, 오프라인, 영상이 밖으로 안 나감
- whisper.cpp는 빌드 `b5454`(Windows x64 CPU)로 고정, 처음 쓸 때 내려받음
- 인식용 소리는 **배경음악 트랙을 빼고** 16kHz 모노로 추출
- whisper가 앞 무음까지 문장에 붙이는 문제 → **실제 소리 크기로 자막 시작·끝을 말소리에 맞춤**(오차 약 0.1초)
- 자막 입히기: 앱에서 자막을 **투명 PNG로 그려 FFmpeg로 겹치는 방식**
  (미리보기와 같은 그리기 코드를 써서 보이는 그대로, 한글 글꼴 문제도 없음)
- 자막 편집: 목록 편집, 타임라인 끌기, 스타일, SRT 불러오기/저장

## 로드맵 이후 추가한 기능

### 프로젝트 저장/불러오기
- `.vproj`(JSON)에 경로 + 편집 내용만 저장, 상대 경로도 함께
- 경로만으로 다시 열 수 있도록 미디어 로딩을 blob URL → **`media://` 사용자 프로토콜**로 변경
  (영상 위치 이동을 위한 Range 요청 지원, 썸네일·음파를 위한 CORS 헤더)
- 원본이 없으면 다시 연결 + 같은 폴더 자동 탐색
- 저장 안 한 변경 표시(●), 닫기 전 확인

### 자동 저장·복구, 최근 프로젝트
- 30초마다 앱 데이터 폴더에 자동 저장, 정상 저장/"저장 안 함"으로 닫으면 삭제
- 시작 시 자동 저장본이 있으면 = 비정상 종료 → 복구 창
- 최근 10개 기억

### 전환 효과
- CapCut처럼 **두 클립이 겹치는 방식**. 내보내기는 FFmpeg `xfade` + `acrossfade`
- 미리보기는 CSS로 흉내 냄. FFmpeg 결과를 프레임별로 재서 방향·곡선을 맞춤
  (예: 검은 화면 거치기는 앞 화면이 20% 안에 사라지고 뒤 화면이 30%부터 나타남, 원형 열기 반지름 = max(0, 3q−1)×대각선/2)

### 텍스트 레이어
- 자막 입히기 방식을 일반화: 텍스트 + 자막을 **한 장의 그래픽 레이어**로 그림
- 내보낼 때 화면이 바뀌는 시점마다 한 장, **애니메이션 구간만 프레임 단위**로 그림
- 미리보기에서 글자를 직접 끌어 위치 이동

### 설치 파일
- electron-builder NSIS, 설치 위치 선택, 바로가기, `.vproj` 파일 연결, 중복 실행 방지(이미 켜진 창에서 열기)
- 앱 데이터 폴더를 `%APPDATA%\video-editor`로 고정 (개발판·설치판이 같은 데이터 사용)
- FFmpeg는 asar 밖(`app.asar.unpacked`)에 두어 실행 가능하게

## 검증 방식

- 편집 로직(reducer): Node의 TypeScript 실행으로 단위 테스트
- 내보내기: 테스트 영상을 만들어 실제 렌더링 → 길이·프레임 색·구간별 소리 크기 측정
- 화면: 실제 앱을 `--remote-debugging-port`로 띄워 CDP로 조작·캡처 (복구 흐름, 자동 저장, 전환 미리보기, 텍스트 끌기, 패키지 앱의 자동 자막까지)
