# 코드 구조

## 프로세스 나눔

```
렌더러 (src/, React)  ── window.editorApi (preload.cjs) ──  메인 프로세스 (electron/, Node)
 화면·편집 로직·미리보기                                      파일·FFmpeg·whisper·대화상자
 media://local/<경로>  ──────── 파일 읽기 (Range 지원) ────────  mediaProtocol.cjs
```

## 파일별 역할

### electron/ (메인 프로세스, Electron 없이 node로 단독 테스트 가능하게 분리)
| 파일 | 역할 |
|---|---|
| `main.cjs` | 창, IPC 처리, 앱 데이터 폴더 고정, 중복 실행 방지, `.vproj` 인자 열기, 닫기 전 확인 |
| `preload.cjs` | 렌더러에 노출하는 API (`window.editorApi`) |
| `exporter.cjs` | 타임라인 → FFmpeg 인자. 내보내기, 음성 인식용 오디오 추출, 녹음 WAV 변환 |
| `transcriber.cjs` | whisper.cpp 내려받기·실행, 자막 시작·끝 보정 |
| `mediaProtocol.cjs` | `media://` 프로토콜 (Range, CORS) |
| `projectFiles.cjs` | `.vproj` 읽기/쓰기, 상대 경로, 다시 찾기, 최근 목록, 자동 저장 |

### src/ (렌더러)
| 파일 | 역할 |
|---|---|
| `App.tsx` | 전체 상태 연결, 선택, 단축키, 저장/열기/복구 흐름 |
| `types.ts` | 데이터 모델 |
| `state/project.ts` | 편집 로직(reducer) + 실행취소 기록, 메인 트랙 배치, 전환 겹침 계산 |
| `state/playback.ts` | 재생 시계 (외부 스토어) |
| `state/projectFile.ts` | 프로젝트 파일 직렬화/검증, 저장 안 됨 판단 |
| `utils/exportPlan.ts` | 내보내기 계획 만들기, 그래픽(텍스트·자막) 붙이기 |
| `utils/graphics.ts` | 텍스트 레이어·자막 그리기(미리보기·내보내기 공용), 그래픽 구간 PNG 만들기 |
| `utils/subtitles.ts` | 자막 그리기, SRT 읽기/쓰기 |
| `utils/transitions.ts` | 전환 목록과 미리보기용 모양 |
| `utils/media.ts` | 미디어 불러오기·썸네일·음파, `media://` 주소 |
| `components/*` | 화면 조각 (Timeline, Preview, 각종 Inspector·Dialog·Panel) |

### 기타
- `scripts/run-electron.cjs`: 개발 실행 시 `ELECTRON_RUN_AS_NODE` 제거 후 Electron 실행
- `scripts/make-icon.cjs`: `build/icon.png` 생성
- `.vscode/settings.json`: `release/` 감시 제외

## 데이터 모델 (types.ts 요약)

```ts
Project {
  clips: Clip[]          // 메인 트랙은 배열 순서 = 재생 순서
  subtitles: Subtitle[]  // 시작 순
  subtitleStyle
  texts: TextLayer[]     // 시작 순, 뒤일수록 위에 그림
}
Clip { id, mediaId, track: 'main'|'audio'|'voice', start, in, out, speed, volume, fadeIn, fadeOut, transition? }
```
- 클립 길이 = `(out − in) / speed`
- 메인 트랙 시작 위치는 `layout()`이 계산: 앞 클립 끝 − 전환 겹침
- 전환은 **들어오는(뒤) 클립**에 저장. 실제 겹침 = min(설정, 앞 클립 길이/2, 뒤 클립 길이/2)

## 실행취소

- 모든 편집은 `historyReducer`의 action으로 처리 (기록 100개)
- 슬라이더·글자 입력처럼 연달아 오는 변경은 `mergeKey`로 하나로 묶고, 손을 떼면 `endMerge`
- `removeMedia`는 과거 기록에서도 해당 클립을 지움, `load`는 기록을 비움

## 주요 흐름

### 미리보기
- 클립마다 `<video>`/`<audio>`를 두고, 재생 시계에 맞춰 재생·정지·위치 보정(0.3초 × 배속 이상 어긋나면)
- 다음 클립은 1초 전에 미리 위치 이동
- 전환 중에는 두 클립을 모두 보이고 CSS(opacity·transform·clip-path)로 효과, 소리 배율도 교차
- 맨 위 캔버스에 텍스트·자막을 그림(내보내기와 같은 코드), 텍스트 끌기도 이 캔버스에서 처리

### 내보내기 (exporter.cjs)
1. 메인 트랙 구간을 각각 정확한 길이로 만듦 (화면 비율 맞춤, 빈 곳은 검은 화면 + 무음)
2. 구간을 하나씩 잇기: 전환이 있으면 `xfade` + `acrossfade`, 없으면 `concat`
3. 그래픽 PNG들을 ffconcat 목록으로 이어 `overlay`
4. 배경음악·녹음은 `adelay`로 위치를 맞춰 `amix`
5. libx264 + AAC, 진행률은 `-progress pipe:1`

### 자동 자막 (transcriber.cjs)
엔진·모델 확인/다운로드 → 배경음악을 뺀 16kHz 모노 WAV 추출 → `whisper-cli -l ko -ml 40 -sow -oj` → JSON 파싱 → 소리 크기로 시작·끝 보정

### 그래픽 내보내기 (graphics.ts)
텍스트·자막이 바뀔 수 있는 시점들로 구간을 나눔 → 애니메이션 구간은 프레임마다, 나머지는 한 장씩 PNG → 아무것도 없는 구간은 비움(투명 PNG로 채움)
