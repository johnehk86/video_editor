# 만들면서 겪은 문제와 해결

## 실행·빌드

**VS Code 안에서 Electron이 일반 Node처럼 동작 (`require('electron')`이 경로 문자열)**
- 원인: VS Code가 `ELECTRON_RUN_AS_NODE` 환경 변수를 물려줌
- 해결: `scripts/run-electron.cjs`에서 이 변수를 지우고 실행. Electron을 띄우는 테스트도 같은 처리 필요

**처음 실행할 때 `spawn UNKNOWN`**
- 새로 내려받거나 빌드한 실행 파일을 Windows가 검사하는 동안 실행이 막힘
- 해결: 몇 초 뒤 다시 실행하면 됨

**electron-builder가 `EPERM: rename ... win-unpacked.tmp` 로 실패**
- 작업 폴더 안의 `release` 폴더가 잠겨서 이름 바꾸기 실패 (작업 폴더 밖에서는 성공 → VS Code 폴더 감시 등으로 추정)
- `.vscode/settings.json`에 감시 제외를 넣었지만 바로 해결되지 않음
- 해결: `build.electronDist`로 설치된 Electron을 복사하게 해서 압축 풀기·이름 바꾸기 단계 자체를 건너뜀

**Vite 설정 경고(ESM in CommonJS)**
- `vite.config.ts` → `vite.config.mts`로 이름 변경

## 미디어

**저장한 경로만으로 영상을 다시 열 수 없음**
- blob URL은 그 순간의 파일 객체에만 묶임
- 해결: `media://` 프로토콜로 로컬 파일 직접 읽기. Range 요청을 지원해야 영상 위치 이동이 됨

**`media://` 영상으로 썸네일을 캔버스에 그리면 막힘(오염된 캔버스)**
- 해결: 응답에 `Access-Control-Allow-Origin: *`, `<video crossOrigin="anonymous">`

**브라우저 녹음(WebM)은 길이 정보가 없고 위치 이동이 부정확**
- 해결: 저장할 때 FFmpeg로 WAV 변환

## 자막·인식

**whisper가 앞쪽 무음까지 첫 문장에 붙임 (말은 2초부터인데 자막은 0초부터)**
- 해결: 인식용 WAV의 10ms 단위 소리 크기로 각 자막의 시작·끝을 말소리 구간으로 좁힘 (앞 0.1초, 뒤 0.15초 여유)

**FFmpeg `drawbox`로 만든 테스트 PNG가 보이지 않음**
- 투명 바탕 위에 그리면 알파가 0으로 남음 → 테스트용 PNG는 `geq`로 알파를 직접 지정 (앱은 캔버스로 그리므로 해당 없음)

## 전환

**미리보기와 내보내기의 모양을 맞추기**
- FFmpeg `xfade` 결과를 10% 간격 프레임으로 재서 방향·곡선을 확인한 뒤 CSS로 재현
- 밀기/닦기 방향: `slideleft`는 뒤 화면이 오른쪽에서 들어옴, `wipeleft`는 오른쪽부터 드러남

## 개발 도구

**셸에서 따옴표·역슬래시가 섞인 스크립트가 깨짐**
- heredoc 안의 node 스크립트에서 `'\\'`, 정규식 `\.` 등이 사라지거나 따옴표 짝이 안 맞음
- 해결: 수정 스크립트를 파일로 쓰거나 편집 도구로 직접 수정

**자동 테스트에서 화면 캡처 좌표가 어긋남**
- 이 PC 화면 배율이 150%(`devicePixelRatio` 1.5)라 캡처 이미지가 CSS 크기보다 큼 → 좌표에 배율을 곱함
