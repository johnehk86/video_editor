## 관리 측면에서 할 일

- **git 저장소 만들기**: 아직 git이 아님. 단계별 기록·되돌리기를 위해 `git init` 권장
- **테스트를 저장소에 넣기**: 단위 테스트·내보내기 검증·화면 자동 테스트를 작업용 임시 폴더에서 돌렸기 때문에 지금은 남아 있지 않음.
  다시 만들 때 참고: Node의 TypeScript 실행으로 reducer 테스트, `electron/` 모듈은 node로 직접 호출, 화면은 `--remote-debugging-port` + CDP + `VIDEO_EDITOR_USER_DATA`

## 알려진 한계

- 미리보기 볼륨은 100%까지 (내보내기는 200%까지 반영)
- 미리보기에서 4배를 넘으면 브라우저가 소리를 끄고 화면이 끊길 수 있음 (내보내기는 정상)
- 클립이 바뀌는 순간 미리보기가 아주 잠깐 끊길 수 있음 (내보내기는 정상)
- 자막·텍스트는 영상 클립과 따로 움직임 → 클립 순서를 바꾸거나 전환을 넣은 뒤 위치 확인 필요
- 영상 클립을 음소거(0%)하면 그 말소리는 자동 자막에서 인식되지 않음
- 300MB가 넘는 파일은 음파를 그리지 않음
- 실행취소 기록은 프로젝트 파일에 저장되지 않음
- 원본 영상·녹음 파일을 지우면 프로젝트에서 빈 부분이 됨 (다시 연결 필요)
- 전환은 메인 트랙 클립 사이에만
