# 실행과 빌드

## 명령어

| 명령 | 하는 일 |
|---|---|
| `npm install` | 의존성 설치 (처음 한 번) |
| `npm run dev` | 개발 모드 실행 (Vite + Electron, 화면 코드는 저장하면 바로 반영) |
| `npm run build` | 타입 검사 + 화면 빌드(`dist/`) |
| `npm run dist` | **설치 파일** 만들기 → `release\영상편집기-설치-0.1.0.exe` |
| `npm run dist:dir` | 설치 없이 실행되는 폴더만 만들기 → `release\win-unpacked\VideoEditor.exe` |
| `node scripts/make-icon.cjs` | 앱 아이콘 다시 만들기 |

- `electron/` 쪽 코드를 바꾸면 화면 새로고침으로는 반영되지 않음 → 앱을 끄고 `npm run dev` 다시 실행
- 개발 모드에서 창을 닫으면 터미널에 "exit code 1"이 보이는데, 개발 서버가 함께 꺼지면서 나오는 정상 메시지

## 데이터 저장 위치

| 내용 | 위치 |
|---|---|
| 녹음 파일(WAV) | `%APPDATA%\video-editor\recordings` — 프로젝트가 이 파일을 쓰므로 지우지 말 것 |
| whisper 엔진·모델 | `%APPDATA%\video-editor\whisper` |
| 최근 프로젝트 목록 | `%APPDATA%\video-editor\recent-projects.json` |
| 자동 저장본 | `%APPDATA%\video-editor\autosave\autosave.vproj` |
| 내보내기 설정·마이크 선택 등 | 앱 안의 localStorage |

- 개발판과 설치판이 **같은 폴더**를 씀 (`main.cjs`에서 고정)
- 테스트할 때 환경 변수 `VIDEO_EDITOR_USER_DATA`로 다른 폴더를 쓰게 할 수 있음

## 설치 파일 설정 (package.json `build`)

- productName `영상 편집기`, 실행 파일 `VideoEditor.exe`
- NSIS: 설치 위치 선택 가능, 바탕화면·시작 메뉴 바로가기, 한국어 설치 화면
- `.vproj` 파일 연결
- `asarUnpack: node_modules/ffmpeg-static/**` — FFmpeg 실행 파일은 asar 밖에 있어야 실행됨
- `electronDist: node_modules/electron/dist` — 이 PC에서 폴더 잠김(EPERM) 문제를 피하려고 설치된 Electron을 그대로 복사
- React 등은 화면 빌드에 포함되므로 devDependencies, 실행용 의존성은 `ffmpeg-static`뿐

## 설치 시 주의

- **코드 서명이 없어서** 처음 실행하면 "Windows의 PC 보호" 경고 → **추가 정보 → 실행**
- 경고를 없애려면 유료 코드 서명 인증서 필요 (개인 사용에는 불필요)
